# Caso de Uso - Sistema de Gestão de Estoque

## Atores

### Funcionário

É o usuário responsável por controlar os produtos do estoque.

## Caso de uso principal

O funcionário pode realizar as seguintes ações:

- Cadastrar produto;
- Visualizar produtos;
- Editar produto;
- Excluir produto.

## Cadastro de produto

1. O funcionário acessa o sistema.
2. Preenche os dados do produto.
3. Clica em "Cadastrar".
4. O sistema valida os dados.
5. O produto é salvo no banco de dados.
6. O sistema volta para a lista de produtos.

## Visualização dos produtos

1. O funcionário acessa o sistema.
2. O sistema consulta os produtos cadastrados.
3. Os produtos são mostrados em uma tabela.

## Edição de produto

1. O funcionário escolhe um produto.
2. O sistema apresenta os dados cadastrados.
3. O funcionário muda as informações.
4. O sistema valida os dados.
5. As mudanças são salvas.

## Exclusão de produto

1. O funcionário escolhe um produto.
2. O sistema recebe o identificador do produto.
3. O produto é excluído do banco de dados.
4. O sistema volta para a lista de produtos.
